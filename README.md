# Happy Bees Pickleball

Court organiser for the Happy Bees Pickleball group. Runs every court at once with fair rotation from the bench, live standings and session history.

**Open the app:** https://calcodeit.github.io/happy-bees-pickleball/

## What it does

- Runs all courts at the same time. Each court finishes on its own and the next four players from the bench step straight on.
- Fair rotation: whoever has played the fewest games goes on next, and partners and opponents are mixed up so everyone plays with everyone.
- Optional "even teams" pairing based on win rate.
- Tracks wins, losses and standings through the night, with an optional score for each game.
- Copy a summary at the end of the night and save each session to history.
- Works offline and can be added to a phone's home screen like an app.

Player names and results are saved on the organiser's device only. Nothing is stored in this repository.
